# Project Nexus: Convertible Bond Arbitrage Engine

Project Nexus is a high-fidelity, client-side, single-page web application that simulates an institutional-grade UI for a multi-agent AI system. The system's purpose is to analyze convertible bonds for potential merger arbitrage opportunities, with all analytical tasks being simulated in the user's browser using the Google Generative AI SDK.

This project was built to demonstrate a complex, interactive, and responsive UI driven by client-side AI, without the need for a backend or a build process.

## Features

*   **100% Client-Side**: The entire application runs in the browser. No backend, no build steps.
*   **AI-Powered Analysis**: Uses the `@google/genai` SDK to simulate a multi-agent analysis workflow.
*   **Sequential Agent Execution**: Visualizes the real-time status (`Idle`, `Running`, `Success`, `Error`) of three specialized AI agents (Catalyst, Valuation, Covenants) as they run in order.
*   **Dynamic UI**: The dashboard instantly updates as the user selects different bonds and as analysis results become available.
*   **Final Synthesized Report**: After successful analysis, a final investment report is generated by a "Nexus" master agent.
*   **Modern Frontend**: Built with React 19 and TypeScript.
*   **Build-Free Setup**: All dependencies are loaded via an importmap from a CDN (`esm.sh`).
*   **Responsive Design**: Styled with Tailwind CSS for a seamless experience on all screen sizes.
*   **Accessible**: Includes ARIA attributes for screen readers and keyboard-navigable elements.

## Technology Stack

*   **Framework**: [React 19](https://react.dev/)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **AI**: [Google Generative AI SDK (`@google/genai`)](https://github.com/google-gemini/generative-ai-js)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/) (via CDN)
*   **Dependencies**: Loaded via importmap from [esm.sh](https://esm.sh/)

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

*   A modern web browser (e.g., Chrome, Firefox, Safari, Edge).
*   A Google Gemini API Key. You can get one from [Google AI Studio](https://aistudio.google.com/app/apikey).
*   A local web server to serve the files. This is necessary to avoid issues with browser security policies (CORS) when loading module scripts. A simple one can be run with Python or Node.js.

### Installation & Setup

1.  **Clone the repository:**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **Create the environment file:**
    This project requires your Gemini API key to be available in the browser.
    *   Rename the `env.js.example` file to `env.js`.
    *   Open `env.js` and replace `"YOUR_GEMINI_API_KEY"` with your actual API key.

    ```javascript
    // env.js
    window.process = {
      env: {
        API_KEY: "YOUR_GEMINI_API_KEY",
      },
    };
    ```

3.  **Serve the application:**
    You need to serve the project directory using a local web server.

    *   **Using Python:**
        ```bash
        # If you have Python 3
        python3 -m http.server
        ```
        ```bash
        # If you have Python 2
        python -m SimpleHTTPServer
        ```

    *   **Using Node.js (with `serve`):**
        ```bash
        # Install serve globally if you don't have it
        npm install -g serve
        # Run the server
        serve .
        ```

4.  **Open the application:**
    Once the server is running, open your web browser and navigate to the provided URL (usually `http://localhost:8000` or `http://localhost:3000`). The Project Nexus application should now be running.
